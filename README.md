# Portfolio Website

This repository contains the source code for my personal portfolio website.

The site is designed to clearly present:
- Product case studies
- Shipped work across web and mobile
- My role, scope, and decision-making as a Product Owner / Product Engineer
- Links to live projects and demos

The focus is **clarity, credibility, and scanability** for hiring managers and recruiters.

## Tech Stack

This portfolio site is intentionally simple and fast.

- **Frontend:** React / Next.js  
- **Language:** TypeScript  
- **Styling:** CSS  
- **Deployment:** (Vercel)

Individual projects showcased on the site use a range of stacks, including Flutter, Firebase, PostgreSQL, and AI integrations.

---

## Design Principles

This portfolio is built around a few core principles:

- **Outcome > buzzwords**
- **Decisions > features**
- **Ownership > titles**
- **Clarity > cleverness**
- **Real constraints > toy problems**

Everything shown here is defensible in interviews.
